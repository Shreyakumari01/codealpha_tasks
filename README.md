# CodeAlpha Internship Projects

This repository contains two projects developed as part of the CodeAlpha Internship.

## 1. Language Translation Tool

A language translation application that allows users to translate text from one language to another.

**Technologies:** Python, Streamlit

**Project Structure:**

```text
CodeAlpha_Language_Translation_Tool_Project/
│
└── LanguageTranslationTool.py
```

## 2. CustomerCare – E-commerce FAQ Chatbot

An NLP-based chatbot that answers frequently asked questions related to e-commerce, including order tracking, payments, shipping, returns, and cancellations.

**Technologies:** Python, Streamlit, NLTK, Pandas, Scikit-learn

**Project Structure:**

```text
CodeAlpha_Chatbot_for_FAQs_Project/
│
├── app.py
├── train.jsonl
└── requirements.txt
```
